# Criterios de aceptación

- Inicia con Python 3.11.
- Funciona sin API externa mediante proveedor simulado.
- Carga una imagen, varias imágenes o una carpeta.
- Ofrece botones directos para archivos y carpeta, y admite arrastre sobre la ventana.
- Impide sustituir las imágenes durante un análisis activo.
- Procesa todas las imágenes válidas.
- Muestra progreso, conteos, confianza y resultados consolidados.
- Presenta imagen original y anotada.
- Genera interpretación orientativa sin diagnóstico.
- Exporta un PDF legible.
- Presenta las acciones de exportación en una ventana, sin menús desplegables.
- Maneja errores sin cerrar abruptamente.
- No incluye secretos ni rutas absolutas.
- Todas las pruebas pasan.
