# Código de conducta

## Compromiso

La comunidad de VECTOR UroSight busca un entorno respetuoso, inclusivo y técnicamente riguroso. No se toleran acoso, discriminación, ataques personales, divulgación de información privada ni conductas que comprometan la seguridad de otras personas.

## Alcance

Estas reglas aplican a issues, pull requests, discusiones y demás espacios públicos asociados al proyecto.

## Aplicación

Reporte incidentes de forma privada al responsable del proyecto. No publique información clínica, credenciales ni detalles sensibles dentro de un reporte público. Las conductas incompatibles podrán resultar en eliminación de contenido o restricción de participación.
